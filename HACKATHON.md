## Selected Problem Statement
**PS 1: Intelligent Git Conflict Resolution with Testing Provenance**

## AI Models Used
No AI model has been integrated yet. We will select an open-source/open-weight model and integrate it meaningfully into the project.

## Project Goal
We aim to build a Git-integrated tool that helps developers resolve merge conflicts by providing context about the origin of conflicting changes and their testing history.

The tool will help developers understand which changes have been tested, which are production-tested, and which are still unverified.
