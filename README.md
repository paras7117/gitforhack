# Stech - Git Conflict Resolution

## What are we building?

We are working on a tool that can help developers deal with Git merge conflicts. Sometimes developers work on different branches and make changes to the same code, which creates conflicts.

We want to make this process easier by showing where the changes came from and whether they have been tested or not.

## What do we want to do?

- Find where a change originally came from.
- Check whether the changes have been tested.
- Identify changes that are already tested in production.
- Help developers understand conflicts before resolving them.
