# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
The `git-provenance` team takes software and Git repository security seriously.

If you believe you have discovered a vulnerability related to:
- Malformed Git conflict marker injection
- Git Notes command injection
- Provenance signature forgery
- AI prompt escape during conflict resolution

Please do **NOT** open a public issue. Instead, report your findings via email to:
`security@hacktoberfest2026.org`

Reports will be acknowledged within 24 hours with a mitigation timeline.
